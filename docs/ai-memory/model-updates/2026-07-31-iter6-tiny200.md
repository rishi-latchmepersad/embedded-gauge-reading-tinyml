## Sample-level diagnosis (11 test_2 images)

- The mean is dragged up by ONE hflip variant: sample 8 (GT center
  (0.865, 0.169), pred (0.785, 0.435)) = **178px error**; all three scale
  heads fail on it (85-178px). The model has never seen flipped views.
- Most upright samples: 9-20px errors with high confidence (0.96-1.00) and
  near-perfect radius — consistent with coarse-head quantization on tiny
  gauges (24x24 head = 16px cells at 384).
- Confidence is saturated (0.96-1.00 everywhere), so confidence gating
  cannot rescue the failures.

## Decision

iter7 = universal_v1 + tiny200 + **50% random hflip in on-the-fly
augmentation** (cx mirrored exactly; WACV 2024-style flip/rotate
augmentation). The flip is applied before scale/translate so it stays
consistent with the target transform. Launcher: `tmp/run_iter7_hflip.sh`.

If hflip does not fix test_2: consider a finer tiny-band head (48x48 grid
already exists; the 24x24 head quantization is a hard floor for the
smallest gauges) or explicit hflip of the 11 train_2 originals.
